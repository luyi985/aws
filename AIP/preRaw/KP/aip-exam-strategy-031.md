# aip-exam-strategy-031: AIP-C01 exam question formats and scenario reasoning

## Learning Objective

Recognize the AIP-C01 question formats and apply a disciplined approach to multi-option scenarios.

## Scope

- Included: multiple-choice, multiple-response, ordering, matching, and no partial credit.
- Excluded: memorizing particular exam questions.

## Source Context

This is the closing course-planning KP, grounded in the supplied study guide rather than external exam claims.

## Knowledge Point

The guide describes multiple-choice and multiple-response questions, plus ordering and matching formats. Multiple-response and the newer formats offer no partial credit, so each selected relationship or sequence must satisfy the whole scenario rather than merely contain one plausible option.

## Logical Path

1. Read the requested outcome and constraints.
2. Identify the AWS/GenAI capability that directly meets them.
3. Eliminate options that violate a stated constraint.
4. For multi-part formats, verify every selected element and its order or pairing.

## Key Terms

- Multiple response: question requiring more than one selected answer.
- Ordering: question requiring responses arranged in a correct sequence.

## Example

For a question requiring current policy facts with minimal retraining, choose a retrieval-based design and reject a fine-tuning-only option. This demonstrates using requirement clues to evaluate alternatives.
