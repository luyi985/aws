# saa-containers-apprunner-110: 从应用源到托管服务（AWS App Runner）

## Learning Objective

在“提交镜像后由平台运行可扩展 API”的场景中，能说明从应用源到托管服务的判断依据，并指出适用限制。

## Scope

- Included: 从应用源到托管服务的核心机制、适用条件与所引页面的边界。
- Excluded: 完整部署教程、未引用的扩展功能、实时价格与最新配额。

## Source Context

所列课件或本地笔记提供课程依据。本次按课程范围整理，未对该服务的全部现行功能逐项核验。逻辑路径是学习组织与推导，示例为说明机制而构造，不作为原资料中的真实案例。

## Knowledge Point

应用托管服务从源代码或镜像构建并部署 Web 服务，管理伸缩和入口等基础设施。

## Logical Path

1. 需求：提交镜像后由平台运行可扩展 API。
2. 适用性取决于部署形态与应用所需的网络连接。
3. 结果：应用托管减少维护基础设施组件的工作。

## Key Terms

- AWS App Runner：应用托管服务从源代码或镜像构建并部署 Web 服务，管理伸缩和入口等基础设施。

## Example
